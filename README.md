# scap

A tiny screen recorder for Windows. It sits in your system tray and records your screen to a video file with one shortcut.

## What it does

- Records your whole screen, a single window, or an area you pick
- Records sound too, if you want
- Cuts a recording down to just the part you want, right inside the app
- Clean dark settings window

## How to use it

1. Run `scap.exe`. It appears as an icon near the clock.
2. Press a shortcut to start recording. Press it again to stop.

| To record | Press |
|---|---|
| Whole screen | Ctrl + PrtScr |
| A window | Ctrl + Win + PrtScr |
| An area | Ctrl + Shift + PrtScr |

You can change these in Settings (right-click the tray icon).

## Cutting a video

Right-click the tray icon, choose **Trim video...**, and drag the two white handles to pick the part you want to keep. Then save it. Your original video stays untouched.

## Requirements

Windows 10 (version 1903) or newer.
